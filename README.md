# Job Application System

## Developed By
Kittipich Chaisongmueang

## Features

### Management System
- Add Department
- Edit Department
- Delete Department

### Admin Dashboard
- Total Applicants
- Total Departments
- Applicant Status Summary

### Document Management
- Upload Resume (PDF)
- Upload Transcript (PDF)
- Filter Applicants by Department
- Search Applicants

### Applicant Management
- View Applicant Detail
- Update Applicant Status
- Delete Applicant

### Print Optimization
- Print Applicant Information
- A4 Layout Support
- Browser Print Support

---

## Security
- File Validation
- File Type Restriction
- File Size Restriction
- Authentication Middleware

---

## Technologies Used
- Laravel 12
- PHP 8

- Blade Template
- Bootstrap / HTML / CSS
